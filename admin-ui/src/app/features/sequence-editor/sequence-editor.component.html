Each step's Time is how long it waits after the previous step actually ran — not from upload, and not a fixed clock time. A step fires whether the one before it succeeded or failed; nothing ever gets stuck waiting on an outcome. The pipeline only checks what's due once an hour, so a step becomes due on the first check after its wait has passed, not the instant it elapses. This template only applies to the next batch you upload — editing it never changes a campaign that's already running.
