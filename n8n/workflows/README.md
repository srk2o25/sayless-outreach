# Workflow exports

Empty until the first workflow is built in the n8n UI at `http://localhost:5678`.

Expected files (see `../CLAUDE.md` for what each does):
- `daily-scheduler.json`
- `linkedin-dispatch.json`
- `email-send.json`
- `email-events.json`

To load one on a fresh instance: n8n UI → Workflows → Import from File.
